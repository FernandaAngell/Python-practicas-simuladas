# Software FJ – Sistema Integral de Gestión

## Descripción del proyecto

Sistema desarrollado en Python para la gestión de clientes, servicios y reservas de Software FJ, utilizando programación orientada a objetos e interfaz gráfica con Tkinter.

## Tecnologías utilizadas

- Python 3
- Tkinter
- Programación orientada a objetos (POO)

## Estructura del proyecto

El proyecto contiene los siguientes archivos:

- `main.py`: archivo principal para iniciar el sistema.
- `interfaz.py`: contiene la interfaz gráfica.
- `clientes.py`: gestión de clientes.
- `entidades.py`: clases base del sistema.
- `servicios.py`: gestión de servicios.
- `reservas.py`: gestión de reservas.
- `excepciones.py`: excepciones personalizadas.
- `sistema.log`: registro de operaciones del sistema.

## Instrucciones de descarga y ejecución

1. Ingresar al repositorio de GitHub.
2. Seleccionar el botón **Code** y luego **Download ZIP**.
3. Descomprimir el archivo descargado.
4. Abrir la carpeta extraída. Si aparece una carpeta adicional llamada `Python-practicas-simuladas-main`, ingresar en ella.
5. Identificar la carpeta que contiene directamente el archivo `main.py` junto con los demás archivos `.py`.
6. Abrir esa carpeta en Visual Studio Code.
7. Abrir una terminal desde esa ubicación.
8. Ejecutar el siguiente comando:

```bash
python main.py
```

## Requisitos

- Tener Python 3 instalado.
- Contar con Tkinter, incluido normalmente en la instalación de Python para Windows.

## Importante

El archivo `main.py` debe ejecutarse desde la carpeta donde se encuentran los archivos del proyecto (`interfaz.py`, `clientes.py`, `servicios.py`, entre otros).

No se debe ejecutar desde la carpeta exterior de la descarga, sino desde la carpeta que contiene directamente el archivo `main.py`.
